# PR #2 — Удаление дефолтных тестов NestJS

**Дата мержа:** 2026-07-07

## Обзор

Убраны шаблонные тесты, сгенерированные при инициализации NestJS. Проект очищен от boilerplate-тестов перед написанием собственных.

## Что изменено

### Удалённые файлы

- `src/app.controller.spec.ts` — unit-тест контроллера.
- `test/app.e2e-spec.ts` — e2e-тест приложения.

### Сохранённая инфраструктура

- Конфигурация Jest (`test/jest-e2e.json`) и npm-скрипты для тестов остались без изменений — готовы к добавлению новых тестов.
