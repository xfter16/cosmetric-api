# PR #12 — Спецификации проекта (docs/spec)

**Дата:** 2026-07-09

## Обзор

Добавлен раздел `docs/spec/` с документацией проекта: идея, техническое видение, конвенции, workflow и tasklist. Обновлён индекс `docs/README.md`.

## Что изменено

### Спецификации (`docs/spec/`)

- `idea.md` — описание продукта Cosmetric: сценарии поиска по составу, MVP, аккаунты и модерация.
- `vision.md` — техническое видение MVP: стек, архитектура, структура монорепо, модель данных, деплой.
- `conventions.md` — практические нормы генерации кода (KISS, API-first, стиль TypeScript).
- `workflow.md` — процесс итераций: согласование → реализация → проверка → коммит.
- `tasklist.md` — прогресс по итерациям и итеративный план разработки.
- `README.md` — оглавление раздела spec.

### Прочее

- В `docs/README.md` добавлена ссылка на раздел [spec](../spec/README.md).
- Добавлен `.cursorignore` — исключает `spec/` из индексации Cursor (спеки подключаются вручную через `@`).
