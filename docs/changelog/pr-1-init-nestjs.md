# PR #1 — Инициализация NestJS + TypeScript проекта

**Дата мержа:** 2026-07-07

## Обзор

Базовая инициализация серверного приложения на NestJS с TypeScript. Создан каркас проекта с минимальным HTTP API и инфраструктурой для разработки.

## Что изменено

### Структура приложения

- Добавлен стандартный NestJS-проект: `AppModule`, `AppController`, `AppService`, точка входа `main.ts`.
- Настроены конфигурационные файлы TypeScript (`tsconfig.json`, `tsconfig.build.json`) и Nest CLI (`nest-cli.json`).

### Инструменты разработки

- Подключены ESLint и Prettier с конфигурацией для TypeScript.
- Добавлены скрипты сборки, запуска и тестирования в `package.json`.
- Включены дефолтные unit- и e2e-тесты NestJS.

### Документация

- Добавлен `README.md` с инструкциями по установке, запуску и тестированию.
